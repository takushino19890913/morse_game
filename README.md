# 和文モールスゲーム

和文モールスの見本再生、リズムゲーム、短点・長点からの文字組み立てをひとつにした React/Vite アプリです。

## ローカル起動

```bash
npm install
npm run dev
```

## テスト

```bash
npm test
```

## ビルド

```bash
npm run build
```

## GitHub Pages

このリポジトリには `.github/workflows/deploy-pages.yml` を入れてあるので、GitHub に push したあとに Pages の配信元を `GitHub Actions` にすれば、そのまま公開できます。
